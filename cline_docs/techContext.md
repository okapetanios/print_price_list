# Tech Context

## Technologies Used

- **HTML5:** For structuring the content of the price list.
- **CSS3:** For styling the HTML content, including specific styles for printing.

## Development Setup

- A standard web browser is sufficient for viewing and printing the final HTML file.
- A text editor is used for creating and editing the HTML and CSS files.

## Technical Constraints

- The final output must render correctly in common modern web browsers (Chrome, Firefox, Safari, Edge) for printing purposes.
- CSS should be written to be print-friendly (e.g., using `@media print` queries if necessary).
